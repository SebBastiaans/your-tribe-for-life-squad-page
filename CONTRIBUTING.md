## Code Conventions
- Kebab classname structure
- English titles, issue descriptions can be in Dutch
- Nesting after the top-level elements (`<html>`, `<body>`, `<header>`, `<main>` en `<footer>`)
- Use progressive enhancement
- Build the website according to the RAPPE principle.

### Issues
- One (epic) issue of the whole page with sub-issues of the components of the website.
- For example: [EPIC] or [COMPONENT] in front of the issue name
- Use MosCow tag notations

### Commits
- Link the related issues.
- Give it a descriptive name.

### Pull-request
- Use the template
- At least one reviewer
